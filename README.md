# Radhe Krishna Turtle Graphics

This Python program uses the `turtle` graphics module to draw a symbolic artwork of **Radha Krishna**, representing traditional Indian devotion and artistic expression. The illustration includes detailed features like Krishna’s *morpankh* (peacock feather), *bansuri* (flute), Radha’s *duppata*, and other ornamental details.

## 📌 Features

- **Traditional Indian Art Representation**: Depicts Radha and Krishna using Python's turtle graphics in a symbolic and stylized manner.
- **Scenic Elements**: Includes moon, rectangular platform, turbans, flute, and clothing layers.
- **Customization-Friendly**: Well-commented code for easy learning and modification.
- **Colorful Drawing**: Uses light and traditional pastel colors (e.g., `#ff99d1` for background, `#CDEEF1` for moon).
- **Decorative Text**: Displays “Radhe Krishna…” on screen using turtle’s `write` function.
